# PDFGen Pro 📄✨

A high-performance, professional-grade PDF editor and document processing platform. Built for seamless PDF manipulation, conversion, and OCR extraction.

---

## 🔥 Features

### 🛠️ Professional PDF Editor
- **Modify Existing PDFs**: Add text, images, and annotations directly to your documents.
- **Page Management**: Reorder, delete, or merge pages within any PDF file.
- **Pixel-Perfect Rendering**: High-fidelity PDF processing using industry-standard libraries.

### 🔄 Advanced Document Conversion
- **Multi-Format Support**: Convert Word documents (`.docx`), PowerPoint presentations (`.pptx`), and images to high-quality PDF files.
- **Fast Processing**: Client-side conversion for maximum privacy and speed.

### 🔍 Optical Character Recognition (OCR)
- **Text Extraction**: Transform scanned documents and images into searchable, editable text.
- **Powered by Tesseract.js**: Integrated OCR technology for reliable character recognition.

### 🔐 Secure & Cloud-Enabled
- **Firebase Authentication**: Secure user accounts with Google Sign-In support.
- **Process History**: Keep track of your documents and edits with Firestore-backed persistence.
- **Privacy First**: Most document processing happens directly in your browser.

---

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Modern Vanilla CSS (Glassmorphism & Micro-animations)
- **Backend**: [Firebase](https://firebase.google.com/) (Firestore, Auth, Hosting)
- **Core Libraries**:
  - `pdf-lib` for advanced PDF manipulation
  - `docx` & `mammoth` for Word processing
  - `pptxgenjs` for PowerPoint generation
  - `tesseract.js` for OCR
  - `html2canvas` for UI-to-document exports

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nitin2122/pdfgen.git
   cd pdfgen
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in Development Mode**:
   ```bash
   npm run dev
   ```
